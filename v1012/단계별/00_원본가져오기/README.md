# 00 원본가져오기

- 실행 주체: Hypit 밖(파일 복사)

## 설명
- 하는 일: 사용자 파일을 서버 프로젝트(references\v1012\source.mp4)로 복사, 지문(SHA-256) 비교
- 누가: 사람·에이전트(Hypit 명령 아님)
- 왜 하나: 이후 모든 시각(몇 초에 무엇)이 이 파일 하나 기준 → 같은 파일임을 지문으로 확인

## 지침 한국어 요약
- 지침_한국어.md (따른 절의 원문 핵심 문장 + 한국어 풀이 + 이번 적용)

## 지침(지침\ 폴더, 에이전트용 설명서 — hypit 프로그램이 읽지 않음)
- video-downloads.md (skills/hypit/references/production/video-downloads.md) — 링크로 받을 때의 지침(hypit download). 이번엔 파일을 직접 받아 사용 안 함

## 입력(입력\ 폴더)
- 원본.txt

## 출력(출력\ 폴더)
- sha256.txt
- source.mp4
