## 브리프(5→6 사이)

- 실행 주체: 에이전트(Claude) + 사용자 선택 3개(예시 제품 · 그래픽 방식 · 생성 방식)
- 하는 일: 원본에서 지킬 것과 바꿀 것을 정하고 생성 프롬프트를 씀
- 입력: 05_판단기록 ANALYSIS 「유지할 관계」 7개 · TIMELINE 장면 경계, 사용자 선택(콜드브루 병 · Hypit 안 코드 부품 · 컷별 4초 × 4번 480p)
- 출력: BRIEF.md(가상 브랜드 ONSAE COLD BREW, 장면별 원본 → 콜드브루판 대응표) · prompts\(img_product · img_person · cut1_back · cut2_product · cut3_table · cut4_hold)
- 왜 이렇게 나오나: 내레이션이 애디렉트 홍보라 그대로 두고 「광고 속 예시 제품」만 바꾸는 업종별 변형으로 정함 → 소리·장면 시각을 원본과 같게 유지
- 왜 하나: Hypit 스킬 지침상 Brief = 사용자 목표, Treatment = 창작 답 — 생성 요청을 쓰기 전에 무엇을 지킬지 고정

## 09 재료 생성

- 실행 주체: 외부 모델 — Higgsfield MCP(Hypit 밖), 이미지 Nano Banana Pro · 영상 Seedance 2.0 fast
- 하는 일: 참조 사진 2장(제품 · 인물)을 먼저 만들고, 그 사진을 참조로 실사 4컷을 4초씩 따로 생성
- 입력: prompts\ 6개 · 설정(이미지 1k · 영상 480p · 16:9 · 4초 · 소리 없음) · 참조 = 앞서 만든 사진의 작업 번호(gen\요청기록.json)
- 출력: gen\ref_product.png(ONSAE 라벨 병) · ref_person.png(단발 갈색 머리 여성) · cut1_back · cut2_product · cut3_table · cut4_hold.mp4(864×496 · 24fps · 4.04초) · cuts_sheet.jpg · still_s1~s3.jpg(카드 · 혜택 배경용 정지 화면)
- 비용: 20크레딧(이미지 2 × 2 + 영상 4 × 4) — 사전 조회 값과 같음, 1번 컷 첫 제출은 동시 처리 한도(3개)로 거절돼 과금 없이 재제출
- 왜 이렇게 나오나: 컷마다 따로 4초씩 만들어 컷 경계가 정확함(11/14 15초 한 번 생성 때의 디졸브 · 컷 위치 어긋남 없음), 같은 인물 사진을 참조로 넣어 1 · 3 · 4번 컷 인물이 이어짐, 라벨 「ONSAE」 유지
- 왜 하나: 원본에 없는 장면(새 제품 · 새 인물)은 생성이 필요한 유일한 부분 — 이 단계에서만 돈이 들고 파일이 밖으로 나감
- 밖으로 나간 것: 프롬프트 글 6개 · 설정 값 · 참조(01 · 02 결과를 작업 번호로) · 분석용 context 문장 → Higgsfield → Google(이미지) · ByteDance(영상), 이 PC 에서 올린 파일 없음
- 실제 전송 원문 모음: higgsfield_전송\(요청마다 prompt.txt · 요청.json, README), 프롬프트 파일과 다른 곳 2개 — 컷3 「괸 채 → 괴 채」, 컷4 「휘날린다 → 흩날린다」(요청 작성 때 바뀜)

## 06 설계도 · 부품 작성

- 실행 주체: 에이전트(Claude)
- 하는 일: 콜드브루판 설계도와 그래픽 부품 패키지를 씀
- 입력: BRIEF.md · 생성 결과 · Hypit 설치본 부품 예제(semantic-composition/responsive-explainer, minimal-author-package) · 지침 production/component-visuals.md(「Compose video and graphics in one HTML visual」)
- 출력:
  - src\remake.svml — 재료(원본 소리 · 생성 4컷 · 사진 4장) · 시간 틀(장면 창 15개) · 실사 4자리 Clip · 그래픽 장면 10개 · 자막 · Film
  - packages\addirect-scenes\ — 새 태그 `<promo:Scene>`(scene = bug · title · now · select · upload · ttal · cards · promo · band · end), 문구는 copy 속성, 그림은 image-1~4
  - src\remake.svrun(만들 것 = final.video)
- 왜 이렇게 나오나: Hypit 기본 부품에 업로드 화면 · 카드 쌓기 · 로고 조립 같은 장치가 없어 프로젝트 부품을 직접 씀(장면마다 HTML · CSS + 「프레임 번호 → 그 순간 상태」 함수), 글자는 정확한 글꼴(Noto Sans KR 500 · 900, 손글씨 Nanum Pen Script)로 그림
- 왜 하나: 문구 · 제품 사진을 설계도에서 바꾸면 그래픽까지 다시 렌더 — 이번 콜드브루 문구도 copy 속성만 바꾼 것
- 고친 것: 첫 렌더에서 컨셉 기획 카드 줄 겹침 · 검수 선택 상자 위치 → 부품 수정 후 다시 빌드(2회째 결과가 최종)
