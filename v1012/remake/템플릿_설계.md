## 4. 내레이션 변경 설계

### 4.1 대본 구성

대본을 문장 Segment 5개 + 말 없는 오프닝으로 나눈다. Segment 마다 소리 출처를 따로 고를 수 있게 한다.

| Segment | 원본 문장 | 원본 구간(초) | 변경 가능성 |
| --- | --- | --- | --- |
| opening | (말 없음, `<pause/>`) | 0.00–1.61 | 없음 |
| n1 | 지금 보시는 이 광고 AI로 만들었어요. | 1.61–4.35 | 낮음(업종명 삽입 정도) |
| n2 | 이미지만 넣으면 딸깍! | 4.75–6.57 | 낮음 |
| n3 | 모든 과정이 자동으로 이루어져요. | 7.37–9.66 | 중간 |
| n4 | 영상 제작 기간 한정 무료! | 10.42–12.26 | 높음(혜택 · 기한 · 가격) |
| n5 | 모두의 TV 광고 애디렉트! | 12.64–14.42 | 낮음 |

### 4.2 변경 수준

| 수준 | 내용 | 소리 출처 | 비고 |
| --- | --- | --- | --- |
| A 그대로 | 내레이션 전부 원본 | 원본 소리 | 현재 콜드브루판 |
| B 일부 교체 | 바꿀 Segment 만 새 음성, 나머지 원본 | 원본 구간 + 새 음성 클립 | 원본 소리에 음악이 섞여 있어 문제(4.4) |
| C 전체 교체 | 전 Segment 새 음성 | 사내 TTS(gpu103, 무료) 또는 HypiHub 음성(유료) | 음악 · 효과음 별도 트랙 필요 |

### 4.3 구현 방식

- Segment 마다 오디오 재료 하나(원본 잘라낸 구간 또는 새 음성 파일) → 각각 whisperx:Alignment(segment = 해당 Segment) → 시간 틀에서 Segment 창을 차례로 이어 붙임(앞 창 끝 = 다음 창 시작 + 쉼)
- 장면 창 · 순간은 3장 시간 기준대로 semantic:Window · semantic:Instant 로 만들어 부품 `during` · 순간 속성에 넘김 → 문장 길이가 바뀌면 장면이 따라 이동
- 새 문장 길이는 생성 전에 `hypit estimate --text "…" --language ko --pace normal` 로 재고, 전체가 15초 송출 길이를 넘지 않게 조정
- 문장 사이 쉼(원본 0.4 · 0.8 · 0.76 · 0.38초)은 템플릿 값으로 두어 리듬 유지

### 4.4 원본 소리의 음악 문제

- 원본 소리는 내레이션과 배경 음악이 한 트랙으로 섞여 있다(11/11 음량 측정: 말 없는 구간에도 -20~-24 dB 배경 소리)
- B 수준에서 원본 구간 사이에 새 음성을 끼우면 음악이 끊긴다 → 선택지 2개
  - 음악 분리: 원본에서 음성 · 음악 분리 후 음악은 전체 그대로, 음성만 구간 교체(분리 도구 · 품질 확인 필요)
  - 음악 교체: 새 배경 음악을 전체에 깔고 내레이션은 C 수준(전체 새 음성)으로 — 가장 단순
- 효과음(「딸깍」 클릭 등)은 순간에 붙는 별도 오디오 클립으로 둔다(sound-mix.md 「Attach sound to the event it answers」)

## 6. 실사 컷 · 생성

- 프롬프트를 Prompt Kit(.svs)로 만든다: 고정 문장(구도 · 조명 · 「글자 없음」) + 빈칸(제품 · 인물 · 장소)
- 참조 사진 2장(제품 · 인물) → 컷별 4초 생성(11/16 방식, 약 20크레딧/편)
- 생성 경로: Higgsfield(현재) 또는 Hypit 안 생성(HypiHub · BYOK) — 광고주 소재는 경로별 전송 · 보관 확인 후 결정
- 같은 컷 재사용: .svrun 의 build-record · satisfy 로 생성 컷 · 정렬 재사용 → 문구 · 자막만 바꿀 때 생성비 0

## 7. 파일 구성(제안)

| 위치 | 내용 |
| --- | --- |
| template\base.svml | 뼈대(장면 · 층 · 시간 기준) |
| template\variants\<이름>\values | 변형별 교체 값(문구 · 사진 · 내레이션 문장 · 소리 출처 · 자막 · 테마 선택) |
| template\recipes\captions-*.svs | 자막 형식 레시피 |
| template\recipes\theme-*.svs | 그래픽 테마 |
| template\kits\cut-*.svs | 실사 컷 Prompt Kit |
| packages\addirect-scenes\ | 그래픽 부품(테마 속성 추가) |
| template\make_variant.py | 값 파일로 변형 설계도 찍어내기 |

- .svrun 에서 설계도 안 문구 값을 바꿔 끼울 수 없다(11/05 확인) → 변형마다 설계도 한 벌을 생성 스크립트로 찍어낸다
- 다른 Author Source 를 불러와 값을 넘기는 방식은 지침에 「may import other Author or Recipe Sources」만 있고 값 넘기기 가능 여부는 확인하지 않았다

## 9. 확인 필요 사항

- 원본 소리의 음성 · 음악 분리 품질(분리 도구 미정)
- 사내 TTS 목소리와 원본 내레이션 목소리 차이 — 일부 교체(B) 때 이어 들으면 어색할 수 있음
- 문장 길이가 늘어 15초를 넘을 때 줄일 곳(쉼 · 오프닝 · 엔드카드 유지 시간)
- 부품이 Instant 입력을 받는 방식(예제 responsive-explainer 의 `reveal` 과 같은 방식으로 구현 예정, 미검증)
- 광고주가 직접 쓰는 서비스로 제공하면 Hypit 상업 라이선스 필요(사내 제작은 무관)
