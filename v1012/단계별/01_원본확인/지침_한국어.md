# 01 원본 확인 — 지침 한국어 요약

- 원문: 같은 폴더 지침\ (영어, Hypit 0.3.1 스킬)
- 구성: 따른 절 → 원문 핵심 문장(인용) → 한국어 풀이 → 이번 적용
- 지침 = 에이전트용 설명서, hypit 프로그램은 읽지 않음

## reference-video.md › Make time visible

> The local `hypit media` commands expose the source at the scale needed:
>
> - `probe` gives duration, dimensions, frame rate and audio presence;

- 풀이: 로컬 `hypit media` 명령으로 원본을 필요한 크기로 펼쳐 봄, probe = 길이·크기·프레임률·소리 유무

## 이번 적용

- `hypit media probe source.mp4 --json` → 15.015초 · 1920×1080 · 29.97fps · 소리 있음
